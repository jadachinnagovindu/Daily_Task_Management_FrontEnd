# Daily_Task_Management_FrontEnd
**Daily Task Manager** | React.js, Java, Spring Boot, Spring Data JPA, MySQL

- Developed a full-stack web application to create and manage daily tasks.
- Implemented REST APIs for creating, retrieving, updating, and deleting tasks using Spring Boot and Spring Data JPA.
- Managed task details such as title, description, due date, priority, and status.
- Created a dashboard to track tasks and monitor their progress.
